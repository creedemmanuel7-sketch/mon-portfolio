Sika signifie « or » en akan. Direction artistique indigo #1E3A5F, cuivre #B87333 et os — volontairement distincte du thème sombre ambre du portfolio Crédo.ai.

Problème

Montrer une compétence e-commerce concrète — pas seulement des maquettes. Il fallait un parcours crédible : marque, catalogue, panier, paiement test, commande en base — comme pour un vrai client lifestyle.

Approche

  • Étape 1 — brief, personas, flows, wireframes HTML.
  • Étape 2 — design system + ~20 écrans UI HD (prototype navigable).
  • Étape 3 — app Vite/React, 40 produits, panier, Stripe Checkout, Supabase orders.
  • QA — paiement carte test 4242…, persistance commande, recherche par email.

Ce que j’ai construit

Design system & voix de marque
Catalogue 40 SKU + images produit
Checkout Stripe (session + API locale / Netlify)
Commandes Supabase + page « Mes commandes »

Résultat

Une démo bout-en-bout prête pour le portfolio : le process Design → Dev → paiement → data est visible et rejouable. La boutique est consultable sur GitHub Pages ; le checkout Stripe réel tourne en local (ou via Netlify Functions).
