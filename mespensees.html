Case study · Mobile

MesPensees

Un journal intime privé, 100 % local, conçu pour que les pensées restent sur l’appareil — chiffrement, biométrie, mode leurre et widgets Android inclus.

Site vitrine Code source

Rôle

Product & Dev solo

Stack

React Native · Jest · Notifee

Focus

Privacy · Local-first · UX

Problème

Les journaux cloud exposent des notes très personnelles. Sur mobile, il manquait une app claire, offline, avec un vrai contrôle de la vie privée — sans compte, sans sync forcée.

Approche

  • Stockage local-first : les données ne quittent pas l’appareil.
  • Couche sécurité : PIN / biométrie, chiffrement, mode leurre.
  • UX immersive : timeline, capsules temporelles, widgets et notifications.
  • Qualité : architecture contextuelle React Native + tests Jest.

Fonctionnalités clés

Chiffrement + verrouillage biométrique
Mode leurre pour masquer le vrai journal
Capsules temporelles (notes différées)
Widgets Android & notifications Notifee

Résultat

Un produit mobile complet, déployé avec site vitrine, qui démontre ma capacité à mener un projet de bout en bout : produit, sécurité, UX et engineering.
